# AWS Cloud Club

This repository contains the codebase that powers the official Unilorin AWS Cloud Club website.

## Prerequisites

- Node.js 20 or later
- npm

## Setup

```sh
git clone https://github.com/AWS-SBG-UNILORIN-DEV/Official_website.git
cd Official_website
npm ci
```

## Available Scripts

```sh
npm run dev
npm run build
npm run preview
npm run lint
npm run typecheck
npm run format:check
```
